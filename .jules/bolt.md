## 2024-07-04 - [SonarCloud curly braces]
**Learning:** SonarCloud enforces strict maintainability rules on new or modified code. Always use curly braces `{}` around control flow statements (e.g., `if`, `for`, `while`) to prevent CI Quality Gate failures.
**Action:** When touching code, always add curly braces to control flow statements to pass SonarCloud's maintainability checks.
